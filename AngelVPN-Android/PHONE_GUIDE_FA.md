# راهنمای ساخت APK فقط با گوشی (بدون کامپیوتر)

## خلاصه
سورس را در GitHub آپلود می‌کنید → GitHub خودش APK می‌سازد → از بخش Releases دانلود می‌کنید.

---

## مرحله ۱: ساخت حساب GitHub (اگر ندارید)
1. از مرورگر گوشی بروید به: https://github.com
2. Sign up → ثبت‌نام با ایمیل

## مرحله ۲: ساخت مخزن (Repository)
1. روی + بالای صفحه بزنید → New repository
2. اسم بگذارید مثلاً: `AngelVPN-Android`
3. Public را انتخاب کنید
4. Create repository

## مرحله ۳: آپلود فایل ZIP
روش آسان با گوشی:

### روش A — از سایت GitHub
1. وارد مخزن جدید شوید
2. پایین صفحه روی **uploading an existing file** بزنید
   (یا Add file → Upload files)
3. فایل‌های داخل ZIP را از حالت فشرده خارج کنید
4. همه پوشه و فایل‌ها را انتخاب و آپلود کنید
   (مهم: محتویات پوشه AngelVPN-Android را آپلود کنید، نه خودِ پوشه خالی)
5. پایین صفحه Commit changes

### روش B — اپ GitHub موبایل
1. اپ رسمی GitHub را از Play Store نصب کنید
2. مخزن را باز کنید → Code → سه نقطه → Add file / Upload

## مرحله ۴: صبر برای ساخت خودکار
1. بعد از آپلود، بروید به تب **Actions**
2. ورک‌فلو **Build APK** باید شروع شده باشد (چند دقیقه طول می‌کشد)
3. وقتی سبز شد (Success)، روی همان run بزنید
4. پایین صفحه بخش **Artifacts** → فایل `AngelVPN-debug` را دانلود کنید
5. فایل را از حالت فشرده خارج کنید تا به `.apk` برسید

## مرحله ۵: دانلود از Releases (راحت‌تر)
اگر ورک‌فلو موفق باشد، یک Release هم ساخته می‌شود:
1. تب **Releases** در صفحه مخزن
2. روی آخرین نسخه بزنید
3. فایل `.apk` را دانلود و نصب کنید

## نصب روی گوشی
1. تنظیمات → امنیت → نصب از منابع ناشناس را برای مرورگر/فایل‌منیجر فعال کنید
2. روی APK بزنید و نصب کنید

## اگر Actions خطا داد
- مطمئن شوید فایل `gradlew` و پوشه `.github/workflows` آپلود شده باشند
- در Actions روی run قرمز بزنید و Log را بفرستید

## نکته
این APK فاز ۱ است: ایمپورت کانفیگ و UI کار می‌کند، تونل واقعی DNS هنوز وصل نیست.
